A separate photo for every fighter card. Abilities use the first card’s photo for that fighter type.

🌿 Warcrier Photos

  1. Drag the green button to your browser’s bookmarks bar. Show the bar with Ctrl+Shift+B if needed. Clicking the button on this installer page won’t edit Warcrier.
  2. Build your roster, then open Warcrier’s print page in the same browser where you built it. Select Standard Fighter Cards and Show fighter images on abilities.
  3. Click your new Warcrier Photos bookmark. Choose an individual fighter card (for example 1/2 or 2/2), select a photo, drag/zoom in the circular preview, and press Apply photo.
  4. Print or save as PDF. The editor stays out of the printout.

Each card has its own photo. Ability thumbnails always use card 1’s photo (or original artwork if card 1 has no custom photo). Images and editable crops are saved in this browser on Warcrier’s origin. Run the bookmarklet again after reloading to restore them. Close the editor with ×; click the bookmark to reopen it. Restore original removes only the selected card’s saved photo. Duplicate cards are numbered in sheet order; their photos follow those numbered positions.

Install manually / copy bookmark URL

Create a bookmark named Warcrier Photos and paste this entire value into its URL field.

Try the local demonstration · Run browser checks

No account or server upload is needed. PNG, JPEG, WebP, AVIF and GIF are supported when your browser can decode them; animated images become a still crop. Sources are resized to at most 1800 pixels; crops are 800 × 800. Keep original photos separately.
